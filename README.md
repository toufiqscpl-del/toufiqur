# Geospatial Portfolio — GitHub Pages Starter

A responsive personal portfolio for a geospatial data analyst / geographer. Built with plain HTML, CSS, and JavaScript, so there is no build process or package installation.

## Files
- `index.html` — page content and project entries
- `style.css` — layout, colors, responsive styles
- `script.js` — mobile menu, project filters, current year
- `assets/` — create this folder for your own maps, field photos, figures, and CV PDF

## Publish with GitHub Pages
1. Sign in to GitHub and create a **public** repository named `YOUR-USERNAME.github.io` (replace with your actual GitHub username).
2. Upload `index.html`, `style.css`, `script.js`, and this README to the repository's root.
3. Open **Settings → Pages**. Under the build/deployment section, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. Wait a few minutes. Your site should be available at `https://YOUR-USERNAME.github.io/`.

If you use a repository with a different name, your URL will usually be `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

## Personalize before publishing
1. Search `index.html` for `Your Name`, `your.email@example.com`, and `UPDATE YEAR`.
2. Add your real LinkedIn and GitHub profile URLs.
3. Replace sample text with accurate dates, skills, qualifications, publications, and project outcomes.
4. Add your CV PDF to the repository (for example, `assets/cv.pdf`) and update the CV link.
5. Add approved screenshots, maps, field photos, and report previews. Use relative paths, such as `assets/land-cover-map.png`.
6. For each project, include a short description, your role, tools, data sources, methods, and result. Link to a GitHub repository, report, or map where appropriate.
7. Remove any employer/client material you do not have permission to publish. Never upload confidential datasets, personal survey information, API keys, or private coordinates.

## Suggested project write-up
- **Problem:** What question did you investigate?
- **Data:** What datasets and dates did you use?
- **Method:** What GIS/RS tools and analysis steps did you apply?
- **Result:** What did you find or produce? Include a map or screenshot.
- **Your contribution:** What did you personally do?
- **Reproducibility:** Link to code, metadata, or a sanitized sample dataset if shareable.

## Editing
You can edit the files directly on GitHub by opening a file and clicking the pencil icon, or edit locally in VS Code and push the changes to your repository.
